Delete Your Data

By default Naova has no account and no server: Everything you log is stored only on your own device. That means you are always in control of your data and can remove it yourself, instantly. (The one exception is the optional Cloud Backup feature, which you can turn on or off yourself — see below.)

Delete individual entries

Open any attack, check-in, or cycle entry in the app and delete it. The change takes effect immediately on your device.

Delete everything

Uninstall Naova from your device. Because your data lives only in the app's private on-device storage, uninstalling permanently removes all of it — attacks, check-ins, cycle entries, and any saved weather context. This cannot be undone, so export a backup first if you want to keep a copy.

Backups you exported

If you previously exported a backup file, it is wherever you chose to save it (for example your own cloud drive or Files). Delete that file from that location to remove that copy.

Cloud Backup (if you turned it on)

If you use the optional Cloud Backup, your backup is stored encrypted with a key only you hold, so no one else can read it. To remove it: turn Cloud Backup off in the app (this deletes the stored copy), or email us using the button below with the subject Data Deletion Request and we will delete the stored encrypted backup for you.

Anonymous diagnostics

Naova sends only pseudonymous, non-health diagnostic and crash information (via Firebase) to help keep the app stable; it is not linked to your identity — there is no name or account attached to it. Uninstalling the app stops any further collection. Because this information is anonymous, it is not tied to you individually, and the analytics provider automatically deletes it after a limited retention period. If you have a specific privacy concern, email us using the button below and we will help where we can.
